# 一键复现（确定性部分）

这个目录用来验证：**同样的输入和账本，会得到同样的修改单和守门结论。**

## 运行

```bash
cd reproduce
python reproduce.py
```

不需要联网，也不需要 API Key。预期输出：

```
[PASS] 单元测试：79 项，全部通过
[PASS] Q30：抽取 8 条；修改单 可信 6 / 待验证 2；守门退出码 0，待验证 0
[PASS] Q16：抽取 10 条；修改单 可信 8 / 待验证 2；守门退出码 0，待验证 0
全部通过：检查部分可逐次复现。
```

## 它复现了什么

| 能逐字复现 | 说明 |
|---|---|
| 79 项单元测试 | 抽取、证据比对、守门、选稿等程序行为 |
| 抽取 | 同一份草稿，抽出的候选条数相同（Q30 八条、Q16 十条） |
| 修改单 | 同一份账本，分档结果相同（可信/待验证条数一致） |
| 守门 | 同一份终稿与账本，退出码与待验证条数一致 |

## 它不能复现什么

**文章生成**。30 题的 SK 稿由模型生成，输出有随机性，模型版本也会变化；重跑会得到“同一流程下的另一组文字”，不会逐字相同。所以这个脚本只复现“检查”这一半，不假装能复现“写作”那一半。
