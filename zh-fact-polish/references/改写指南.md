# 改写指南

## 事实类
| 情况 | 改法 | 例 |
|---|---|---|
| 可信，但文中没写来源 | 在句中自然带出来源和时间 | "截至2024年12月，我国网民规模达11.08亿" → "据CNNIC第55次统计报告，截至2024年12月……" |
| 待验证：找不到原始出处 | 补证据；仍无法核实就明确标记未核实或删除，不用模糊措辞掩盖缺证 | "筛选了380多个提取物" → 查明数量来源；找不到就登记未核实或删除该数值断言 |
| 存疑：与证据矛盾 | 按证据改正数字、年份、人名 | 年份错写成 1904 → 按证据改为正确年份 |
| 模糊化来源（"据统计""研究表明"） | 写明是谁、何时的统计；写不出就删掉"据统计"，改为观点表述 | "据统计，我国每年浪费……数以千万吨计" → 给出具体机构和年份，或改为"我国餐饮浪费问题突出" |
| 新闻稿超出素材 | 删除素材里没有的人名、数字、引语和细节 | 素材没说"掌声雷动"，就不写 |
| 参考文献信息不符 | 按 report 给出的登记信息改刊名、页码、年份、DOI | — |
| 参考文献查无此文 | 删除该条并同步删改正文引用，或换成能检索到的真实文献 | — |

## 表达类
| 代码 | 问题 | 改法 |
|---|---|---|
| E1 | 表达不顺：语病、成分残缺、搭配不当、长句、"的"字链、"对…进行…" | 补全成分；一句只讲一层意思；"对数据进行分析"→"分析数据" |
| E2 | AI 腔：对举句、段尾金句、套话、高频抽象比喻（温度/底色/土壤） | 正面直述；段落用事实或推论收尾；把比喻换成具体的人和事 |
| E3 | 前后矛盾：同一对象前后数字或说法不一 | 以证据或素材为准统一；无法确定就只保留有依据的一处 |
| E4 | 钻牛角尖：一段里反复"当然…但是…然而…"、反复界定"不是…而是…" | 保留一次必要的让步，其余删掉；直接回答题目要回答的问题 |
| E5 | 空转：段落没有新信息，只是换个说法重复前文或素材 | 删除该段，或补上前文没有的具体例子、数据、分析；不要用新的空话替换空话 |

## 通用原则
- 只改被标出的句子。
- 删掉的空话不要用另一句空话补上。篇幅变化超过 15% 警告、超过 30% 阻断；如大幅删减确有必要，单独说明，不为凑字数补空话。
- 改不了就说明原因，不要硬改。
